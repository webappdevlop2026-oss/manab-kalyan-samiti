# পূজার ছবি আপলোড

- সাল জানা থাকলে `2026` বা `২০২৬`-এর মতো নামের ফোল্ডারে ছবি রাখুন। ২০২৬-এর জন্য `2026` ফোল্ডার প্রস্তুত আছে।
- নতুন সাল যোগ করতে `photos` ফোল্ডারে **Add file → Create new file** খুলে ফাইলের নাম হিসেবে যেমন `2027/.gitkeep` লিখে কমিট করুন। তারপর সেই ফোল্ডারে ছবি আপলোড করুন।
- সাল উল্লেখ করতে না চাইলে সরাসরি `photos` ফোল্ডারে ছবি আপলোড করুন। এগুলো **অন্যান্য ছবি** বিভাগে দেখা যাবে।
- GitHub-এ সেই ফোল্ডার খুলে **Add file → Upload files** থেকে একসঙ্গে একাধিক ছবি বেছে নিন। এরপর পরিবর্তন কমিট করুন।
- JPG, JPEG, PNG, WebP, AVIF ও GIF গ্রহণ করা হয়। ছবির ফাইলের নামটি গ্যালারিতে ক্যাপশন হিসেবে দেখা যাবে।
- `main` শাখার পরবর্তী সফল Vercel প্রকাশে ছবিগুলো **সব পূজার ছবি** বিভাগে দেখা যাবে।
